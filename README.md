# Korea IPTV Live M3U

Auto-updated Korean TV live stream playlist, optimized for playback in China.

## Configuration URL

```
https://raw.githubusercontent.com/<YOUR_USERNAME>/kr-iptv/main/kr_live.m3u
```

Replace `<YOUR_USERNAME>` with your GitHub username.

## Features

- Auto-updated every hour via GitHub Actions
- Only includes verified playable streams
- VLC buffer optimization (10s cache, auto-reconnect, custom UA)
- 58+ Korean TV channels

## How to Use

1. Open your IPTV player (VLC, KODI, TiviMate, etc.)
2. Add the M3U playlist URL above
3. Enjoy!
